## TI_206 判据要点（重要）

- **TI_206F**（主控）：SOP 焙烧区间 **850~910℃**。
- **TI_206E**：工艺确认独立区间 **850~1100℃**，**不套用** TI_206F。
- **TI_206A / TI_206B**：正常范围与报警上下限**待工艺确认**，因此**未生成**区间规则；
  仅按联锁口径保留 TI_206B **>1150℃** 的 P1 保护定值。
- 联锁（>1150℃）为独立保护定值，不受上述判定口径影响。

## 未转为告警规则的项目（原因）

| SOP 项 | 原因 |
|--------|------|
| 空压机压力 ≥0.5 MPa | 无明确对应测点（`仪表用气压力PK_k401` 当前为空） |
| 磨机进风口压力 -0.5~-1 kPa | 无对应测点 |
| 磨机震动值 ≤3 mm/s | 无振动测点 |
| 天然气流量 ~20 m³/h | 与现测点量程口径不符（FI_203 现 107、FI_803 现 128） |
| 空气流量 500~800 m³/h | 与现测点量程口径不符（现 9385） |
| 布袋进口温度 Ti212 ≥220℃ | 是「提窑频」的**操作触发点**，非报警上限 |
| 还原率 ≥96% / 过筛率 ≥95% / 120目过筛率 ≥96% | 化验室指标，非在线仪表 |
| 原矿烘干后水分 ≤6% | 化验室指标 |
| 2# 天然气压力 80~85 kPa | 2# 无独立压力测点 |
| 设备电机温度 ≤65℃（通用） | 无统一测点，已落到 4 个具体轴承/减速机温度 |

## ⚠️ 为何默认停用

SOP 限值针对「**投料后正常生产**」稳态；点火升温期天然越限。写入时以当前实测比对，
**9 条若启用会立即越限**，需工艺先确认测点口径/工况：

- 1#窑体温度TI_206F（现 825.6，<850）
- 1#窑体温度TI_206E（现 822.0，<850）
- 1#窑冷却器废气温度TI_205（现 44.5，<250）
- 1#窑天然气压力PI_201（现 78.6，<80）
- 1#窑窑头压力PI_206A（现 -15.6，<-10）
- 2#窑体温度TI_806F（现 809.5，<850）
- 2#窑冷却器热风出口温度TI_805（现 36.9，<250）
- 2#窑窑头压力PI_805A（现 -11.7，<-10）
- 2#窑窑头压力PI_806B（现 43.3，>20）

其余（含全部 P1 联锁/天然气压力上限、烘干出口温度、磨机温度、部分压力低限等）
当前在范围内，可在规则配置中直接启用。

## 启用方式

- 界面：告警中心 → 规则配置 → 对应行「启用」。
- 或脚本：修改 `scripts/seed-sop-rules.mjs` 中 `enabled` 后重跑（幂等）。
